Bienvenida

Este sitio explica dos pilares del lenguaje HTML: los hipervínculos, que conectan documentos entre sí, y los elementos semánticos, que describen el significado de cada parte de una página.

Todo el sitio está construido sin CSS ni JavaScript, para que puedas ver cómo luce HTML nativo y estudiar su código fuente (clic derecho → Ver código fuente).

¿Por qué es importante?

  • Accesibilidad: los lectores de pantalla entienden mejor la página.
  • SEO: los buscadores identifican el contenido principal.
  • Mantenimiento: el código es más fácil de leer para otros desarrolladores.
  • Navegación: los enlaces unen páginas y secciones en una red de información.

Dato curioso

Tim Berners-Lee creó la World Wide Web en 1989. La idea central era justamente el hipertexto: documentos unidos por enlaces.
