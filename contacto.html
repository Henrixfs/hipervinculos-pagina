Preguntas frecuentes

¿Es obligatorio usar elementos semánticos?

No; el navegador mostrará la página igual. Pero mejoran la accesibilidad, el SEO y la legibilidad del código.

¿Cuántos <header> puede tener una página?

Varios: uno para la página y uno dentro de cada <article> o <section> si lo necesitan. En cambio, solo debe haber un <main>.

¿Por qué este sitio no tiene colores?

Porque está hecho solo con HTML nativo. El diseño visual se agrega después con CSS.
