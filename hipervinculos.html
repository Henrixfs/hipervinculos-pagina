¿Qué es un hipervínculo?

Un hipervínculo (o enlace) es una referencia que permite saltar de un documento a otro, o a otra parte del mismo documento. En HTML se crea con el elemento <a> (de anchor, ancla) y su atributo href. 

<a href="destino.html">Texto del enlace</a>

Tipos de enlaces

1. Enlace absoluto (externo)

Usa la URL completa, incluyendo el protocolo. Sirve para ir a otros sitios web.

<a href="https://developer.mozilla.org/es/">MDN Web Docs</a>

Resultado: MDN Web Docs

2. Enlace relativo (interno)

Apunta a un archivo del mismo sitio, tomando como referencia la ubicación actual.

<a href="semanticos.html">Elementos semánticos</a>

Resultado: Elementos semánticos

3. Enlace a una sección (ancla)

Usa # seguido del id de un elemento. Puede apuntar a la misma página o a una sección de otra página. 

<a href="#atributos">Ir a atributos</a>
<a href="semanticos.html#estructura">Ir a estructura</a>

Resultado: Ir a atributos · Ir a estructura

4. Abrir en una nueva pestaña

El atributo target="_blank" abre el enlace en otra pestaña. Se recomienda acompañarlo de rel="noopener noreferrer" por seguridad. 

<a href="https://www.w3.org/" target="_blank" rel="noopener noreferrer">W3C</a>

Resultado: W3C (se abre en una pestaña nueva)

5. Enlace de correo electrónico

Con mailto: se abre el programa de correo del usuario. Se pueden añadir asunto y cuerpo.

<a href="mailto:contacto@ejemplo.com?subject=Consulta%20HTML">Escríbenos</a>

Resultado: Escríbenos

6. Enlace telefónico

Con tel: los teléfonos móviles inician una llamada al tocar el enlace.

<a href="tel:+51987654321">+51 987 654 321</a>

Resultado: +51 987 654 321

7. Enlace de descarga

El atributo download indica al navegador que descargue el archivo en lugar de abrirlo.

<a href="index.html" download="pagina-inicio.html">Descargar la página de inicio</a>

Resultado: Descargar la página de inicio

8. Una imagen u otro bloque como enlace

Dentro de <a> se puede colocar una imagen o incluso varios elementos.

<a href="index.html">
  <img src="logo.png" alt="Ir al inicio">
</a>

Importante: el alt de la imagen pasa a ser el texto del enlace, así que debe describir el destino.

Atributos del elemento <a>

Atributos más usados
Atributo Función Ejemplo
href Dirección (URL) del destino. href="pagina.html"
target Dónde se abre el enlace (_self, _blank, _parent, _top). target="_blank"
rel Relación entre la página actual y el destino. rel="noopener noreferrer"
title Información extra que aparece al pasar el cursor. title="Ver más"
download Descarga el recurso en vez de abrirlo. download="archivo.pdf"
hreflang Idioma del documento de destino. hreflang="en"

Buenas prácticas

  • Usa textos descriptivos: Ver guía de formularios es mejor que clic aquí.
  • Avisa cuando un enlace abre una pestaña nueva o descarga un archivo.
  • Agrega rel="noopener noreferrer" a los enlaces con target="_blank".
  • Usa id únicos y descriptivos para las anclas.
  • No uses enlaces para acciones (para eso existe <button>).
Ejercicio: ¿qué está mal en este enlace? 
<a href="https://ejemplo.com" target="_blank">clic aquí</a>

Respuesta: el texto no es descriptivo y falta rel="noopener noreferrer".
